## User-supplied Medieval Battlefield

- Source: Ishak's supplied `Projects/assets/Medieval_Battlefield.blend` and accompanying battlefield handoff/data; raw source remains outside this repository. No separate author/license notice was included, so no third-party license is inferred.
- Used files: `assets/environment/battlefield/battlefield.glb`, `zones.json`; fingerprints and export/QA metrics are in `provenance.json`. Untextured vertex-color terrain, ruins, rocks, bushes and groundcover.
- Engine preparation: Blender 5.2.3 glTF export, Z-up to Y-up, static collision-only helpers, explicit eight-zone conversion, exclusion of character references/rigs/cameras/lights. Three decorative groundcover tiles with coplanar overlaps omitted from the engine copy. Source not modified. Runtime integration/collision/navigation/brush logic are project code.

Battlefield material adaptation: an asset-local Godot post-import script enables the existing linear vertex-color palette; no source colors or textures were replaced.
