# Visual direction v1

`visual_direction_v1.png` is the concept sheet Ishak approved in conversation. It defines the intended faceted low-poly look: red/black coat and wide hat for the Captain; hood, leather, fur, and bone accents for the Hunter; muted stone and foliage; warm orange powder effects.

It is a visual reference, not an exact level plan or verified asset pack preview. The guide remains authoritative for geometry, ability assignments, timing, and HUD behavior. In particular, the illustrative W icon in the sheet is not the Captain's Ration design.
